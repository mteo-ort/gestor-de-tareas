# Gestor de Tareas y Rutinas

Sistema integral desarrollado en Python para la organización, seguimiento y automatización de tareas y rutinas personales, diseñado con una arquitectura desacoplada entre el backend (API REST) y la interfaz de usuario.

## 🎯 Objetivo
Proveer una herramienta robusta para administrar actividades con fechas límite, prioridades y categorías personalizables, incorporando un sistema de alertas automáticas sobre vencimientos y reactivación de rutinas.

## ⚙️ Funcionalidades Principales
* **Gestión completa (CRUD) y ciclo de vida:** Creación, consulta, modificación, baja y reactivación de tareas y rutinas.
* **Control de estados y prioridades:** Seguimiento mediante estados (*pendiente*, *en progreso*, *completada*) y niveles de prioridad.
* **Clasificación flexible:** Organización mediante categorías personalizables.
* **Sistema de alertas y avisos:** Detección automática de tareas próximas a vencer y atrasadas.
* **Configuración personalizada:** Ajuste de preferencias de usuario y notificaciones.

## 🛠️ Tecnologías Utilizadas
* **Backend / API:** Python, FastAPI, Pydantic
* **Base de Datos:** SQLite (diseño relacional y consultas SQL)
* **Interfaz de Escritorio (Cliente):** PySide6
* **Control de Versiones:** Git y GitHub
