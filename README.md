
# Gestor de Tareas

Aplicación de escritorio desarrollada en Python para organizar y administrar tareas personales de manera sencilla.

## Objetivo

Desarrollar una aplicación que permita gestionar tareas, establecer fechas límite, organizar actividades por categorías y recibir recordatorios sobre próximos vencimientos.

## Funcionalidades previstas

- Crear, consultar, modificar y dar de baja tareas.
- Organizar tareas mediante categorías personalizables.
- Asignar prioridades y fechas límite.
- Gestionar estados: pendiente, en progreso y completada.
- Recibir recordatorios sobre tareas próximas a vencer y atrasadas.
- Configurar las preferencias de la aplicación.

## Tecnologías

- Python
- PySide6
- SQLite
- Git y GitHub
